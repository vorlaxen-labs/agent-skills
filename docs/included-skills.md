# Included skills

This package bundles **one** engineering standards module:

| Module | Id | When to use |
|--------|----|-------------|
| Global | `global` | Every project — [`AGENTS.md`](../AGENTS.md) |

Install with:

```bash
npx @vorlaxen-labs/agent-skills init -y
```

All other skills are integrated from external repos — see [integrations.md](integrations.md).

## Authoring external skills

Follow [SKILL-SPEC.md](../SKILL-SPEC.md) for external skill packs; the bundled **global** module is documented there as well.
